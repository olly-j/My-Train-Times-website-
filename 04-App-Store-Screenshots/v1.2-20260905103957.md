## Evidence and limitations

The first iPhone capture run retained a Premium-menu navigation failure. The
first iPad run retained an onboarding-dismissal race. Corrected capture-only
navigation passed the focused iPad core/Premium rerun and iPhone Premium
rerun. The successful original captures remain linked to their result bundles.
This is capture evidence, not a replacement full app regression matrix.

Real screenshots use the accepted app's existing DEBUG fixtures where available;
they are illustrative data, not a claim of live service at publication time.
The Overground image is explicitly a line-picker view. The two widget frames
show native system gallery previews. The Vision Pro map is static, not a live
vehicle map or the internal Map Preview. No product screen was generated by AI.
